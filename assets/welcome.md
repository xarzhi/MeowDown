# MeowDown

一个用 **Rust + GPUI Kit** 写成的所见即所得 Markdown 编辑器。左侧栏顶部可以切换「文件 / 大纲」，滑块会滑到新的那一半：文件按文件夹层级排成一棵树，大纲列出这篇文档的标题。中间是纸张，写下的每一个 `#`、`-`、`>` 都会立刻变成排版好的样子。

## 它现在能做什么

- 点击任意段落即可就地编辑，光标落在你点的地方，字号和行距纹丝不动
- 在段首输入 `#`、`-`、`>`、`1.`、`- [ ]` 或三个反引号，自动切换块类型
- 回车拆段、列表自动续写、空列表项回车退出列表；上下键走到头会跳进相邻的块
- 新建、打开、保存这些都收进了菜单栏：文件、编辑、段落、格式、视图
- 左侧栏的「文件 / 大纲」：**文件是一棵树**，文件夹点一下展开、当前文档所在的分支自动打开；大纲列出本文标题，点一下滑过去
- `Ctrl+Shift+O` 打开整个文件夹，递归收进所有层级的 `.md`，树里按目录分层显示文件数
- 「文件 → 自动保存」打开后，停手一秒就写回磁盘，不用再按 `Ctrl+S`
- 撤销是按文档记的，改了 A 段再跑去点 B 段，`Ctrl+Z` 照样撤得回来
- 代码块自带语法高亮，有多少行显示多少行，永不出现内部滚动条，也没有缩进竖线，和纸张贴得很紧；聚焦时右下角可以改语言
- 表格：管道表格直接排成真正的表格，表头、对齐、斑马纹都在，`Ctrl+T` 现插一张空表，点单元格就地改
- 超链接按 `[文字](地址)` 排成蓝色下划线，**Ctrl+单击**就用默认浏览器打开
- 数学公式：行内 `$…$` 就着基线排版，独立成行的 `$$…$$` 会上下堆叠分数、伸缩括号
- 图片直接渲染成图，本地相对路径、绝对路径、网络地址都认；点进图片块时源码显示在图片上方
- `Ctrl+V` 粘贴截图：先按本地图片显示，配了图床就自动上传，再把路径换成网络地址
- `Ctrl+,` 打开设置：左边一列菜单切换页面，右边是按组分好的卡片，图床、图片路径、自动保存、文件关联都在里面
- 深色 / 浅色主题，字数统计与阅读时长

> 这一行是引用块。点进来就能改，改完点别处，它又变回引用。

### 图片

`Ctrl+Shift+I` 插入一张图。默认会把它复制到文档旁边的 `assets/` 目录，并写相对路径：

![MeowDown](sample-image.png)

在设置里打开「插入图片时自动上传图床」，同一张图就会先上传，再把路径换成图床返回的网络地址。`Ctrl+Shift+U` 可以把整篇文档里的本地图片一次性传上去。

图床选 PicGo 时，上传前会先看看它的本地服务在不在：没开就自动把 PicGo 启动起来，等端口通了再传，传完把本地路径换成网络地址。程序位置会在安装目录和注册表里找，装到了别处就在「设置 → 图片与图床 → PicGo」里点「修改位置…」指过去。

### 公式

`Ctrl+Shift+M` 插入一个公式块。想在句子里夹一个符号，就用单个 `$` 包起来，它会照着正文的基线排：质能方程 $E = mc^2$，圆的面积 $\pi r^2$，都是这样写出来的。行内公式不打断行距，长短都跟着段落走。

要单独占一行的推导，用两个 `$` 包成一个块：

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

$$
\int_0^\infty e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}
$$

$$
\begin{pmatrix} a & b \\ c & d \end{pmatrix}
\begin{pmatrix} x \\ y \end{pmatrix}
=
\begin{pmatrix} ax+by \\ cx+dy \end{pmatrix}
$$

分数、根号、上下标、求和与积分的上下限、矩阵、`\left( \right)` 会自动长高的括号都认得；希腊字母直接写 `\alpha`、`\pi`。点进公式块，源码出现在公式上方，改完点别处就重新排。

### 表格

`Ctrl+T` 在光标处插一张三列空表。竖线分列，第二行决定对齐：左边写 `:---` 就是左对齐，`---:` 右对齐，`:---:` 居中。

| 块类型 | 语法 | 对齐演示 | 说明 |
| :--- | :---: | ---: | :--- |
| 标题 | `#…######` | 一级到六级 | `Ctrl+1`…`Ctrl+6` |
| 表格 | `\|` 分列 | 右对齐 | `Ctrl+T` |
| 公式 | `$…$` | 行内 | `Ctrl+Shift+M` |
| 代码块 | 三个反引号 | 不折行 | 无内部滚动条 |

点单元格就能就地改字，回车跳到下一个格子，表格底部有「+ 添加一行」；`\|` 可以写出单元格里的竖线。

### 链接

方括号里放显示的文字，圆括号里放地址：[GPUI 官网](https://gpui.rs)。链接是蓝色的，按住 **Ctrl 再单击**，就用系统默认浏览器打开它；不加 Ctrl 的点击照常把光标放到那一行。

方括号里也可以放行内代码，它既是代码片，也是链接：[`Ctrl+T`](https://gpui.rs)。

地址是相对路径时按文档所在目录解析，指向本地文件也可以：[这张示例图](sample-image.png)。

### 快捷键

文件是 `Ctrl+N` / `Ctrl+O` / `Ctrl+Shift+O`（打开文件夹）/ `Ctrl+S` / `Ctrl+Shift+S`，标题是 `Ctrl+1`…`Ctrl+6`，`Ctrl+0` 变回正文。

格式是 `Ctrl+B` 加粗、`Ctrl+I` 斜体、`Ctrl+U` 下划线、`Alt+Shift+5` 删除线、`Ctrl+Shift+`` ` `` 行内代码、`Ctrl+K` 链接、`Ctrl+Shift+M` 公式、`Ctrl+T` 表格、`Ctrl+\` 清格式。

代码块是 `Ctrl+Shift+`` ` ``，或者在一行里敲三个反引号再回车——先别急着写语言，容器右下角随时能补。

视图是 `Ctrl+/` 源码模式、`Ctrl+Shift+L` 侧边栏、`F8` 专注模式、`F11` 全屏；侧栏内容用顶部的「文件 / 大纲」切换。完整清单在设置的「快捷键」页。

### 列表

1. 有序列表会自己编号
2. 回车继续下一条
3. 空行回车就退出

## 一个块模型

编辑器把文档切成一个个**有类型的块**，而不是一大段文本：每个块自己知道是标题还是列表，渲染时交给 Markdown 渲染器，编辑时换成输入框。所以保存下来的仍然是干净的 `.md` 文件，没有隐藏的私有格式。

行内语法（**加粗**、*斜体*、`行内代码`、[链接](https://gpui.rs)）在非编辑状态下照常渲染；点进那一块时才会露出原始标记，和 Typora 的取舍一致。
